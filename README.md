# 𝐕𝐚𝐧𝐢𝐭𝐚𝐬 ✤ — Discord Profile & Portfolio

A modern, dark/cyberpunk personal showcase site with real-time Discord activity, live Spotify playback, background music player, and an interactive Supabase-powered guestbook.

---

### ✨ Features

- 🎮 **Live Discord Presence** — Real-time status, custom activities, and rich presence sync powered by the [Lanyard API](https://github.com/Phineas/lanyard) (WebSocket & REST).
- 🎧 **Interactive Spotify Card** — Shows currently playing tracks with live progress, lyrics support (via LRCLIB), and Spotify embed integration.
- 🎵 **Custom Draggable BGM Player** — Full playlist support with shuffle, volume slider, album art, and draggable positioning with saved state.
- 📚 **Favorites Showcase** — Interactive cards for favorite movies, anime, TV shows, and games with automated poster fetching from Steam, MAL, and Wikipedia.
- 📖 **Discord Guestbook** — Wall powered by Supabase with Discord OAuth sign-in and moderation filters.
- 🎨 **Aesthetic UI & Polish** — Ambient video background, reactive status rain canvas, custom interactive cursor, and fluid responsive design.

---

### 🛠️ Built With

- **HTML5 & CSS3** (Vanilla, modern CSS variables, fluid responsive layouts)
- **Vanilla JavaScript** (ES6+, WebSockets, Canvas 2D, MediaSession API)
- **Lanyard API** (Discord presence synchronization)
- **Supabase** (Guestbook database & Discord OAuth)
- **LRCLIB & Jikan API** (Lyrics sync & anime metadata)
